## Dataset D — Materials Project perovskites
- **Source:** Materials Project API (`next-gen.materialsproject.org`)
- **How to download** (API key required):
  ```bash
  export MP_API_KEY=your_key
  python3 src/data/download_dataset_d.py
  ```
- **Output:** `data/raw/dataset_d/mp_perovskites.csv` — **9,972 materials** matching perovskite stoichiometry (ABX3 / A2BB'X6) with band gap, is_metal, energy_per_atom, symmetry.
- **Target:** `band_gap`
- **Skew:** 5,761 / 9,972 metallic (58% with band_gap=0) — a large, skew-heavy challenge dataset like B.
- **Features:** energy_per_atom, nsites, tolerance factor `t`, octahedral `μ`, composition-averaged elemental descriptors (EN/mass/radius/valence).

> **Note on sizes:** Dataset B is **16,323** rows (public OQMD file), not the 45,570 cited in the PRD — the larger count is the full raw OQMD extraction not publicly distributed. Dataset C (combine) is **1,453** rows. Dataset D (Materials Project) provides ~10k perovskite entries as a large, skew-heavy alternative.

## Dataset B+C combined (deduplicated)
- **Loader:** `load_dataset_combined()` (name: `dataset_combined`)
- **Merge rule:** B (OQMD, 16,323) + C (combine, 1,453), both Chenebuah Magpie with target `Eg`.
  - B-only / C-only formulas kept.
  - Overlapping formulas with consistent Eg (|ΔEg| ≤ 0.01 eV) → keep B's row (one entry).
  - Overlapping formulas with **conflicting Eg** → **dropped** (stays separate in B/C).
- **Result:** 3,644 rows, no duplicate formulas, ~74% metallic (Eg=0). Conflicting drops: 574 of 736 overlaps.
- **Why not naive merge:** 78% of the 736 overlapping formulas have different Eg (up to ~7 eV apart) — a naive merge would inject contradictory labels.

## Dataset E — Zhang double perovskites (2020)
- **Source:** `github.com/FionaZZhang/Machine-Learning-Prediction-of-the-Computed-Band-Gaps-of-Double-Perovskite-Materials` (via matminer `double_perovskites_gap`)
- **Raw file:** `data/raw/dataset_e/double_perovskites_gap.csv`
  - **Shape:** 1,306 rows × 6 cols (`formula`, `a_1`, `b_1`, `a_2`, `b_2`, `gap gllbsc`).
  - **Target:** `band_gap` (renamed from `gap gllbsc`)
  - Feature-engineered from formula: `t`, `μ`, + composition-averaged elemental descriptors (EN, mass, radius, valence).

## Dataset F — NOMAD Perovskite Solar Cells database (2024)
- **Source:** Zenodo `10.5281/zenodo.17240962` (`FAIRmat-NFDI/nomad-perovskite-solar-cells-database`)
- **Raw files:** `data/raw/dataset_f/` (zip + extracted repo).
- ⚠️ **NOT a band-gap regression benchmark.** This is a solar-cell *device* database: schema + A/B/C ion molecular data (Abbreviation, Molecular_formula, SMILE, CAS, etc.) for hybrid-perovskite photovoltaics. It is treated as supplementary material, not plugged into the standard prepare/split/train pipeline.
